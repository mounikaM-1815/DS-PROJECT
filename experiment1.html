EXPERIMENT 1

Reading and Writing CSV, JSON, and Excel Data using Pandas

DATA SCIENCE - 22DS102006 • Department of Computer Science & Engineering

Aim

To perform reading, writing, and format conversion of structured datasets in Python using the Pandas library across three fundamental data formats: CSV (Comma-Separated Values), JSON (JavaScript Object Notation), and Excel (.xlsx) spreadsheets.

Requirements / Tools

  • Hardware: Personal Computer / Workstation (Intel Core i3/i5 or higher, 4GB+ RAM)
  • Operating System: Windows 10/11, macOS, or Linux
  • Software Environment: Python 3.8+, Pandas library, OpenPyXL engine (for Excel support)
  • Interactive Platform: Data Science Web Lab Code Runner / Jupyter Notebook

1. Introduction

Pandas is a Python library used to work with structured data. It provides a DataFrame, which stores data in rows and columns, similar to a table in Excel.

Pandas supports different file formats, including CSV, JSON, and Excel.

Core Data Structure

A DataFrame is a 2-dimensional labeled data structure with columns of potentially different types. It allows rapid data manipulation, slicing, reshaping, filtering, and statistical summaries.

2. Reading and Writing CSV Data

CSV (Comma-Separated Values) is a file format used to store tabular data. Each row represents a record, and commas separate the values.

Reading a CSV file

The pd.read_csv() function reads tabular data from a local file path or a live web URL into a DataFrame.

Reading CSV via URL 
import pandas as pd

url = 'https://people.sc.fsu.edu/~jburkardt/data/csv/hw_200.csv'
df = pd.read_csv(url)
print(df.head())
Explanation:
  • import pandas as pd imports the Pandas library with the standard alias pd.
  • pd.read_csv(url) reads the CSV file directly from the URL.
  • df stores the loaded tabular data as a DataFrame.
  • df.head() displays the first five rows of the DataFrame.

Writing data to a CSV file

Use the to_csv() method to export any Pandas DataFrame to a CSV file on disk.

Writing DataFrame to CSV 
df.to_csv("output.csv", index=False)
Explanation:
  • to_csv() saves the DataFrame as a CSV file.
  • "output.csv" is the output filename.
  • index=False prevents Pandas from saving the row index as an extra column in the file.

3. Reading and Writing JSON Data

JSON (JavaScript Object Notation) is a lightweight data format commonly used to exchange data between applications and web APIs.

Converting to JSON & Reading back 
import pandas as pd

json_data = df.to_json()
df_json = pd.read_json(json_data)
print(df_json.head())
Explanation:
  • df.to_json() converts the DataFrame into a JSON string representation.
  • pd.read_json(json_data) parses and reads the JSON data back into a DataFrame.
  • df_json.head() displays the first five rows of the reconstructed DataFrame.

4. Reading and Writing Excel Files

Pandas can read and write Excel spreadsheets (.xlsx / .xls), which are commonly used in business and research for storing and analyzing tabular data.

Writing & Reading Excel Spreadsheets 
import pandas as pd

# Save data to Excel
df.to_excel("output.xlsx", index=False)

# Read data from Excel
df_excel = pd.read_excel("output.xlsx")
print(df_excel.head())
Explanation:
  • to_excel() saves the DataFrame as an Excel file.
  • read_excel() reads the Excel file into a DataFrame.
  • index=False prevents the row index from being written to the file.

Complete Implementation

Consolidated Pandas File I/O Program

Complete runnable script demonstrating reading and writing across CSV, JSON, and simulated structured tabular workflows:

Complete Solution Program 
import pandas as pd
import io

# 1. Read CSV Data from URL (or local sample)
url = 'https://people.sc.fsu.edu/~jburkardt/data/csv/hw_200.csv'
try:
    df = pd.read_csv(url)
except Exception:
    # Offline fallback dataset with exact matching schema
    csv_data = """Index,Height(Inches),Weight(Pounds)
1,65.78,112.99
2,71.52,136.49
3,69.40,153.03
4,68.22,142.34
5,67.79,144.30
6,68.70,123.30"""
    df = pd.read_csv(io.StringIO(csv_data))

print("=== 1. First 5 Rows of CSV Data ===")
print(df.head())

# 2. Write to CSV
df.to_csv("output.csv", index=False)
print("\n[SUCCESS] DataFrame successfully exported to 'output.csv'")

# 3. Read and Write JSON Data
json_data = df.to_json()
df_json = pd.read_json(io.StringIO(json_data))
print("\n=== 2. First 5 Rows of JSON Reconstructed Data ===")
print(df_json.head())

# 4. Read and Write Excel Files (Demonstration)
print("\n=== 3. Excel File Export / Import Syntax ===")
print("Export: df.to_excel('output.xlsx', index=False)")
print("Import: df_excel = pd.read_excel('output.xlsx')")
print(f"Total Rows: {len(df)}, Total Columns: {len(df.columns)}")
Execution Verification: The script reads structured tabular data into a Pandas DataFrame, exports to CSV without extra index columns, converts to and from JSON representation, and demonstrates Excel spreadsheet I/O.

6. Conclusion

Pandas makes it easy to read, write, and convert structured data between CSV, JSON, and Excel formats. These operations are important for data analysis and data preparation.
