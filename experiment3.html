EXPERIMENT 3

Data Cleaning and Preparation

DATA SCIENCE - 22DS102006 • Department of Computer Science & Engineering

Aim

To perform essential Data Cleaning and Preparation operations in Python using Pandas, NumPy, and re (Regular Expressions) across four fundamental areas:

  • a. Handle Missing Data: Detect NaN values with isna(), drop rows with dropna(), and impute missing entries with fillna().
  • b. Data Transformation: Map categorical attributes to numerical encodings with map(), and rename DataFrame columns using rename().
  • c. Outlier Detection: Identify statistical anomalies using boolean threshold filtering based on z-score limits ($\pm 3\sigma$).
  • d. Regex for Text Manipulation: Tokenize and clean unstructured text with irregular whitespace patterns using Python's re.split().

Requirements / Tools

  • Hardware: Personal Computer / Workstation (Intel Core i3/i5 or higher, 4GB+ RAM)
  • Operating System: Windows 10/11, macOS, or Linux
  • Software Environment: Python 3.8+, Pandas library, NumPy library, built-in re module
  • Interactive Platform: Data Science Web Lab Code Runner / Jupyter Notebook

Theory

Data cleaning and preparation typically consumes up to 80% of a data scientist's workflow. Raw real-world datasets are inherently noisy, containing missing entries, inconsistent categorical labels, extreme anomalies, and unparsed text strings.

  • Missing Data: Missing values are represented in Pandas by np.nan (Not a Number) or None. Ignoring missing data causes computation errors and biases statistical analyses. We can detect them using isna(), eliminate them via dropna(), or impute them using constant or statistical substitutes with fillna().
  • Data Transformation: Machine learning algorithms require numerical inputs. Mapping categorical text strings (e.g. 'male' → 0, 'female' → 1) transforms non-numeric categories into machine-readable format. Renaming column headers ensures consistent naming conventions.
  • Outlier Detection: In standard normal distributions ($\mathcal{N}(0, 1)$), the empirical rule states that 99.73% of observations fall within 3 standard deviations of the mean. Any observation $|x| > 3$ is treated as an extreme statistical outlier.
  • Regular Expressions: Unstructured text data contains unpredictable whitespace, such as multiple consecutive spaces, tab characters (\t), and line breaks (\n). The regex pattern \s+ matches any sequence of whitespace, enabling clean text tokenization.
Part A

a. Handle Missing Data

Identify, drop, and fill missing (NaN) values in a Pandas DataFrame.

Part A: Missing Data Handling 
import numpy as np
import pandas as pd

data = {'A': [1, 2, np.nan], 'B': [4, np.nan, np.nan]}
df = pd.DataFrame(data)
print("=== 1. Missing Value Detection (df.isna()) ===")
print(df.isna())

df_clean = df.dropna()
df_filled = df.fillna(0)

print("\n=== 2. Dropped Missing Rows (df.dropna()) ===")
print(df_clean)

print("\n=== 3. Filled Missing Values (df.fillna(0)) ===")
print(df_filled)
Step-by-Step Explanation
  • import numpy as np, pandas as pd: Imports NumPy for numerical operations/NaN constants and Pandas for DataFrame management.
  • df.isna(): Returns a boolean DataFrame of identical shape, flagging True for missing values and False for valid data.
  • df.dropna(): Removes any row that contains at least one NaN value, preserving only fully observed records.
  • df.fillna(0): Replaces every occurrence of NaN with the specified scalar value 0.

Outcome: Successfully detected missing positions, isolated complete records, and imputed missing attributes with baseline values.
Part B

b. Data Transformation

Map categorical values to numeric codes using a dictionary mapping, and rename DataFrame columns.

Part B: Mapping & Renaming 
import pandas as pd

df = pd.DataFrame({'gender': ['male', 'female', 'male']})

# Map categories to numbers: 'male' -> 0, 'female' -> 1
df['gender_num'] = df['gender'].map({'male': 0, 'female': 1})

# Rename column header from 'gender' to 'Gender'
df_renamed = df.rename(columns={'gender': 'Gender'})
print(df_renamed)
Step-by-Step Explanation
  • df['gender'].map({'male': 0, 'female': 1}): Applies a dictionary mapping across the gender column, creating a new integer-encoded column gender_num.
  • df.rename(columns={'gender': 'Gender'}): Modifies the column header from lowercase gender to capitalized Gender while leaving column data unchanged.
  • print(df_renamed): Displays the transformed DataFrame containing both the original category and its numerical encoding.
Sample Execution Output

0    male           0
1  female           1
2    male           0
Outcome: Categorical attributes were mapped into numeric encodings for modeling algorithms, and columns were renamed to follow standard conventions.
Part C

c. Outlier Detection

Generate random normal observations and identify statistical outliers beyond $\pm 3\sigma$ ($z > 3$ or $z < -3$).

Part C: Z-Score Outlier Detection 
import numpy as np
import pandas as pd

# Generate 100 rows and 3 columns from standard normal distribution
np.random.seed(42)  # For reproducible simulation results
data = pd.DataFrame(np.random.randn(100, 3))

# Detect values exceeding +/- 3 standard deviations
outliers = (data > 3) | (data < -3)
print("Outlier Count per Column:")
print(outliers.sum())
Step-by-Step Explanation
  • np.random.randn(100, 3): Generates a $100 \times 3$ matrix of numbers sampled from a standard normal distribution (mean = 0, std = 1).
  • (data > 3) | (data < -3): Evaluates element-wise boolean conditions using the logical OR operator | to flag values exceeding $3$ standard deviations from the center.
  • outliers.sum(): Calculates column-wise totals of True flags, giving the exact count of outliers detected in each feature.
Sample Execution Output
Outlier Count per Column:
0    0
1    1
2    0
dtype: int64
Outcome: Flagged statistical anomalies outside the $\pm 3\sigma$ threshold across the synthetic normal dataset.
Part D

d. Regex for Text Manipulation

Use Python's standard regular expression library re to normalize and tokenize text containing variable whitespace (spaces, tabs, newlines).

Part D: Regex Text Splitting 
import re

text = "This  is\t a\n test"
split_text = re.split(r'\s+', text)
print("Extracted Word Tokens:")
print(split_text)
Step-by-Step Explanation
  • import re: Imports Python's built-in regular expression engine.
  • text = "This is\t a\n test": Defines a raw string with irregular whitespace (multiple spaces, horizontal tab \t, newline \n).
  • r'\s+': Raw regex pattern where \s matches any whitespace character, and + matches one or more consecutive occurrences.
  • re.split(r'\s+', text): Splits the string by matching variable whitespace boundaries and returns clean tokenized words in a list.
Sample Execution Output
Extracted Word Tokens:
['This', 'is', 'a', 'test']
Outcome: Successfully tokenized irregular text by stripping heterogeneous whitespace delimiters into normalized string tokens.
