4. Data Wrangling

DATA SCIENCE - 22DS102006 • Department of Computer Science & Engineering

Aim

To perform Data Wrangling in Python using Pandas across three fundamental operational areas:

  • a. Perform hierarchical indexing by creating a series with a list of lists (or arrays) as the index, select subsets of data at outer and inner levels using partial indexing.
  • b. Rearrange the tabular data with hierarchical indexing using unstack and stack method.
  • c. Create two different DataFrames and merge them using index as merge key and combine data with overlap using combine_first method.

Requirements / Tools

  • Hardware: Personal Computer / Workstation (Intel Core i3/i5 or higher, 4GB+ RAM)
  • Operating System: Windows 10/11, macOS, or Linux
  • Software Environment: Python 3.8+, Pandas library, NumPy library
  • Interactive Platform: Data Science Web Lab Code Runner / Jupyter Notebook

Theory

Data Wrangling is the critical preparatory phase in data science where raw data is cleaned, structured, reshaped, and enriched into a standardized format ready for downstream statistical inference and modeling.

Key Data Wrangling Concepts in Pandas:

  • Hierarchical Indexing (MultiIndex): Hierarchical indexing is a vital feature of Pandas that enables storing and manipulating higher-dimensional data within 1D (Series) and 2D (DataFrame) tabular objects. With MultiIndex.from_arrays() or MultiIndex.from_tuples(), multiple levels of index keys can be defined. Partial indexing allows querying either the outermost hierarchy (e.g., Department) or navigating into fine-grained inner tiers (e.g., Branch) using .loc[].
  • Tabular Reshaping (unstack and stack): Hierarchical indexes provide an intuitive way to pivot data between wide and long orientations:
    • unstack(): Pivots an indicated row index level into columns, converting stacked row hierarchies into wide tabular representations.
    • stack(): Rotates columns into hierarchical row levels, transforming wide tables into compact long series.
  • Merging on Index & Overlapping Combination (combine_first): Data integration often requires aligning records using row indices rather than column keys. pd.merge(df1, df2, left_index=True, right_index=True) merges datasets by index values. In cases where datasets share overlapping indices and features with missing values (NaN), df1.combine_first(df2) fills in null positions in the first DataFrame with corresponding valid values from the second.

Procedure / Steps

  1. Import the required libraries: import pandas as pd and import numpy as np.
  2. Construct a multi-tiered array structure representing Department and Branch hierarchies.
  3. Generate a pd.MultiIndex object using pd.MultiIndex.from_arrays() with explicit level names.
  4. Bind the multi-index to a pd.Series containing numerical values (marks).
  5. Execute partial indexing queries on the Series at the outer level (e.g., 'Engineering'), inner level (e.g., ('Engineering', 'CSE')), and secondary outer levels (e.g., 'Science').
  6. Create tabular multi-indexed DataFrame structures using pd.MultiIndex.from_tuples().
  7. Apply the unstack() method to pivot the inner row index into columns.
  8. Apply the stack() method to revert the column dimensions back into hierarchical row indices.
  9. Instantiate two separate DataFrames with overlapping index numbers (student IDs) and missing elements.
  10. Perform an outer merge on the DataFrames using left_index=True and right_index=True.
  11. Combine overlapping values using df1.combine_first(df2) to patch missing values.
  12. Verify all outputs against expected results.
Part A

A). Perform hierarchical indexing by creating a series with a list of lists (or arrays) as the index, select subsets of data at outer and inner levels using partial indexing.

Aim

To create a Pandas Series with hierarchical (multi-level) indexing using a list of lists and to select subsets of data using partial indexing at the outer and inner levels.

Syntax
pd.MultiIndex.from_arrays(arrays, names=None)

To create a Series:
pd.Series(data, index=multi_index)

To select data:
series.loc['Outer_Level']
series.loc[('Outer_Level', 'Inner_Level')]
Solution Program 
import pandas as pd

# Create a list of lists for hierarchical index
index = [
    ['Engineering', 'Engineering', 'Science', 'Science'],
    ['CSE', 'ECE', 'Physics', 'Chemistry']
]

# Create MultiIndex
multi_index = pd.MultiIndex.from_arrays(
    index,
    names=['Department', 'Branch']
)

# Create a Series using the hierarchical index
marks = pd.Series(
    [85, 78, 92, 88],
    index=multi_index
)

print("Original Series:")
print(marks)

# Partial indexing at the outer level
print("\nData for Engineering:")
print(marks.loc['Engineering'])

# Partial indexing at the inner level
print("\nData for CSE:")
print(marks.loc[('Engineering', 'CSE')])

# Selecting a subset using both levels
print("\nData for Science:")
print(marks.loc['Science'])

Explanation
  • MultiIndex.from_arrays() creates a hierarchical index with two levels:
    • Outer level: Department
    • Inner level: Branch
  • marks.loc['Engineering'] selects all records under the outer level Engineering.
  • marks.loc[('Engineering', 'CSE')] selects a specific value using both outer and inner levels.
  • marks.loc['Science'] selects all records belonging to the Science department.
Result: The program successfully demonstrates hierarchical indexing and partial indexing at both outer and inner levels in Pandas.
Part B

B). Rearrange the tabular data with hierarchical indexing using unstack and stack method.

Aim

To rearrange tabular data with hierarchical indexing using the Pandas unstack() and stack() methods.

Syntax
unstack()
Converts one level of a hierarchical row index into columns.
DataFrame.unstack(level=-1)
or
Series.unstack(level=-1)

stack()
Converts columns into a hierarchical row index.
DataFrame.stack()
or
Series.stack()
Solution Program 
import pandas as pd

# Create hierarchical index
index = pd.MultiIndex.from_tuples(
    [
        ('Engineering', 'CSE'),
        ('Engineering', 'ECE'),
        ('Science', 'Physics'),
        ('Science', 'Chemistry')
    ],
    names=['Department', 'Branch']
)

# Create tabular data
data = pd.DataFrame(
    {
        '2025': [85, 78, 92, 88],
        '2026': [90, 82, 95, 91]
    },
    index=index
)

print("Original Tabular Data:")
print(data)

# Unstack the inner level
unstacked_data = data.unstack()

print("\nData after Unstack():")
print(unstacked_data)

# Stack the data back
stacked_data = unstacked_data.stack()

print("\nData after Stack():")
print(stacked_data)

Explanation
  1. Hierarchical Indexing: Department and Branch form the two levels of the hierarchical index.
  2. unstack() method: data.unstack() moves the inner index (Branch) from the rows to the columns.
  3. stack() method: unstacked_data.stack() moves the column labels back into the hierarchical row index.
Result: The unstack() method converts row-level hierarchical indexes into columns, while the stack() method converts columns back into hierarchical row indexes.
Part C

C). Create two different DataFrames and merge them using index as merge key and combine data with overlap using combine_first method.

Aim

To create two different Pandas DataFrames, merge them using the index as the merge key, and combine their data using the combine_first() method to fill missing values with available values from another DataFrame.

Syntax
Merge using index:
pd.merge(df1, df2, left_index=True, right_index=True)

combine_first():
df1.combine_first(df2)

The combine_first() method fills the missing (NaN) values in the first DataFrame with corresponding values from the second DataFrame.
Solution Program 
import pandas as pd

# Create the first DataFrame
df1 = pd.DataFrame(
    {
        'Name': ['Ravi', 'Sita', 'Arun'],
        'Marks': [85, None, 78],
        'Grade': ['A', 'B', None]
    },
    index=[101, 102, 103]
)

# Create the second DataFrame
df2 = pd.DataFrame(
    {
        'Name': ['Ravi', 'Sita', 'Kiran'],
        'Marks': [90, 88, 82],
        'Grade': [None, 'A', 'B']
    },
    index=[101, 102, 104]
)

print("First DataFrame:")
print(df1)

print("\nSecond DataFrame:")
print(df2)

# Merge DataFrames using index as merge key
merged = pd.merge(
    df1,
    df2,
    left_index=True,
    right_index=True,
    how='outer',
    suffixes=('_DF1', '_DF2')
)

print("\nMerged DataFrame:")
print(merged)

# Combine data using combine_first()
combined = df1.combine_first(df2)

print("\nDataFrame after combine_first():")
print(combined)

Explanation
  1. Creating DataFrames: Two DataFrames, df1 and df2, are created with student information. Their index values act as student IDs.
  2. Merging using index: pd.merge(df1, df2, left_index=True, right_index=True, how='outer') uses the index as the merge key. The outer merge keeps all index values from both DataFrames.
  3. Combining overlapping data: df1.combine_first(df2) uses values from df1 wherever they exist. If df1 contains a missing value, it takes the corresponding value from df2.
    For example:
    df1 Marks for 102 = NaN
    df2 Marks for 102 = 88
    After combine_first(): Marks for 102 = 88
Result: The program demonstrates both index-based merging and combining overlapping DataFrame data using combine_first().

4. Data Wrangling (Combined Code)

Consolidated program illustrating Hierarchical Indexing, Stack & Unstack, and Index-based Merge & Combine:

Combined Solution Program 
import pandas as pd
import numpy as np

# a. Hierarchical Indexing
data = pd.Series(np.random.randn(6),
                 index=[['a', 'a', 'b', 'b', 'c', 'c'],
                        [1, 2, 1, 2, 1, 2]])
print("a. Hierarchical Series:")
print(data)
print("\nData for 'b':")
print(data['b'])
print("\nInner level 1:")
print(data[:, 1])

# b. Stack and Unstack
df = data.unstack()
print("\nb. Unstacked:")
print(df)
print("\nStacked back:")
print(df.stack())

# c. Merge and Combine
df1 = pd.DataFrame({'a': [1, np.nan, 3], 'b': [4, 5, 6]})
df2 = pd.DataFrame({'a': [7, 8, 9], 'b': [np.nan, 11, 12]})

merged = df1.combine_first(df2)
print("\nc. Combined with combine_first:")
print(merged)
