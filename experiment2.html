EXPERIMENT 2

Interacting with Web APIs and Databases

DATA SCIENCE - 22DS102006 • Department of Computer Science & Engineering

Aim

To retrieve and interact with external data sources in Python using two core techniques:

  • a. Web APIs: Send HTTP GET requests to GitHub's REST API using the requests library and convert JSON issue payloads into a structured Pandas DataFrame.
  • b. Relational Databases: Perform full database lifecycle operations (Create table, Insert, Read, Update, and Delete) with sqlite3 and query tables directly into Pandas DataFrames using pd.read_sql_query().

Requirements / Tools

  • Hardware: Personal Computer / Workstation (Intel Core i3/i5 or higher, 4GB+ RAM)
  • Operating System: Windows 10/11, macOS, or Linux
  • Software Environment: Python 3.8+, Pandas library, Requests library, SQLite3 database engine
  • Interactive Platform: Data Science Web Lab Code Runner / Jupyter Notebook

Theory

Modern data science pipelines rarely rely exclusively on local static files. Data practitioners must dynamically integrate live streams from web services and enterprise relational databases.

1. Web APIs (Application Programming Interfaces)

A REST API allows client applications to communicate with server backends over standard HTTP protocols. When requesting data via GET, servers typically return responses encoded as JSON. The requests library sends requests over the network and serializes response bodies into native Python dictionaries or lists, which Pandas easily converts into rows and columns of a DataFrame.

2. Relational Databases & SQLite

SQLite is a self-contained, serverless, zero-configuration SQL database engine embedded directly within Python's standard library. It provides ACID transactions and allows data engineers to persist structured records in relational tables. Pandas integrates with SQLite via pd.read_sql_query(), allowing SQL queries to return directly as DataFrames.

Part A

GitHub Issues to DataFrame

Fetch open issues from the official pandas-dev/pandas GitHub repository using the GitHub REST API and convert the JSON response into a tabular DataFrame.

Part A: Web API to DataFrame 
import requests
import pandas as pd

url = 'https://api.github.com/repos/pandas-dev/pandas/issues'
response = requests.get(url)
issues = response.json()

df_issues = pd.DataFrame(issues)
print(df_issues[['id', 'title', 'state', 'created_at']].head())
Step-by-Step Explanation
  • requests.get(url): Sends an HTTP GET request to GitHub's REST API endpoint to retrieve the issues of the pandas-dev/pandas repository.
  • response.json(): Parses the raw JSON response payload into a native Python object (a list of dictionaries).
  • pd.DataFrame(issues): Converts the list of issue dictionaries into a structured Pandas DataFrame.
  • print(...): Displays the first 5 issues, showing only the selected columns: id, title, state, and created_at.

Part B

SQLite Database Operations

Establish a database connection, create a table, execute INSERT queries, query data directly into a DataFrame using pd.read_sql_query(), and perform UPDATE and DELETE operations.

Part B: SQLite CRUD Implementation 
import sqlite3
import pandas as pd

# Connect to database
conn = sqlite3.connect("students.db")
cursor = conn.cursor()

# Create table
cursor.execute('''CREATE TABLE IF NOT EXISTS students (id INTEGER, name TEXT)''')

# Insert data
cursor.execute("INSERT INTO students VALUES (1, 'John')")
conn.commit()

cursor.execute("INSERT INTO students VALUES (2, 'Joy')")
conn.commit()

# Read data
df = pd.read_sql_query("SELECT * FROM students", conn)
print("Initial Database Records:")
print(df)

# Update and Delete
cursor.execute("UPDATE students SET name = 'Alice' WHERE id = 1")
cursor.execute("DELETE FROM students WHERE id = 1")
conn.commit()

# Read updated table
df_updated = pd.read_sql_query("SELECT * FROM students", conn)
print("\nAfter Update and Delete (id=1 removed):")
print(df_updated)

conn.close()
Step-by-Step Explanation
  • sqlite3.connect(...): Connects to a database file (students.db). If the file doesn’t exist, SQLite automatically creates it.
  • cursor = conn.cursor(): Creates a cursor object used to execute SQL queries.
  • cursor.execute(...): Executes raw SQL queries such as DDL and DML statements.
  • CREATE TABLE IF NOT EXISTS: Ensures the table schema is created safely without raising duplicate table errors.
  • INSERT INTO: Adds new student records (e.g. id = 1, name = 'John' and id = 2, name = 'Joy').
  • pd.read_sql_query(...): Reads the SQL query result set directly into a Pandas DataFrame for easy analysis and tabular rendering.
  • UPDATE: Updates an existing record's attributes (e.g. changing student name to Alice).
  • DELETE: Removes specific student records matching the filter condition (e.g. WHERE id = 1).
  • conn.commit(): Persists and commits transaction modifications permanently to the database file.
  • conn.close(): Closes the connection to release system resources.

Complete Implementation

Combined Program (Web APIs & Databases)

Consolidated program illustrating both REST API retrieval and SQLite relational database operations in a single script:

Combined Solution Program 
import requests
import sqlite3
import pandas as pd

# ==========================================
# a. GitHub Issues to DataFrame
# ==========================================
print("=== Part A: GitHub Issues Web API ===")
url = 'https://api.github.com/repos/pandas-dev/pandas/issues'
try:
    response = requests.get(url, timeout=5)
    issues = response.json()
    df_issues = pd.DataFrame(issues)
    print(df_issues[['id', 'title', 'state', 'created_at']].head())
except Exception as e:
    # Fallback simulation if offline or rate-limited
    mock_issues = [
        {"id": 2837492101, "title": "BUG: Series.str.replace with regex returns NaN", "state": "open", "created_at": "2026-03-15T10:14:22Z"},
        {"id": 2837489502, "title": "ENH: Support datetime unit conversion", "state": "open", "created_at": "2026-03-15T09:58:11Z"},
        {"id": 2837471203, "title": "DOC: Improve docstring examples for DataFrame", "state": "open", "created_at": "2026-03-15T08:30:45Z"}
    ]
    df_issues = pd.DataFrame(mock_issues)
    print(df_issues[['id', 'title', 'state', 'created_at']].head())

# ==========================================
# b. SQLite Database Operations
# ==========================================
print("\n=== Part B: SQLite Database Operations ===")
conn = sqlite3.connect("students.db")
cursor = conn.cursor()

# Create table
cursor.execute('''CREATE TABLE IF NOT EXISTS students (id INTEGER, name TEXT)''')
cursor.execute("DELETE FROM students") # Clean slate for demo

# Insert data
cursor.execute("INSERT INTO students VALUES (1, 'John')")
cursor.execute("INSERT INTO students VALUES (2, 'Joy')")
conn.commit()

# Read data
df = pd.read_sql_query("SELECT * FROM students", conn)
print("Initial Database Records:")
print(df)

# Update and Delete
cursor.execute("UPDATE students SET name = 'Alice' WHERE id = 1")
cursor.execute("DELETE FROM students WHERE id = 1")
conn.commit()

# Read updated table
df_updated = pd.read_sql_query("SELECT * FROM students", conn)
print("\nAfter Update and Delete (id=1 removed):")
print(df_updated)

conn.close()
