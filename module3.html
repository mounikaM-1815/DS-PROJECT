1. Data visualization: foundation

Data visualization means representing data visually—using charts, plots, and graphs—to make patterns, comparisons, distributions, and relationships easier to understand.

Why visualize data?

  • Understand a dataset quickly: Inspect data structure before modeling or generating analytical reports.
  • Compare values: Evaluate differences across categories or time periods.
  • Find patterns: Identify trends, clusters, unusual observations, and potential outliers.
  • Communicate results: Convey key takeaways to stakeholders who may not want to inspect raw tabular data.
  • Check data quality: Spot unexpected gaps, impossible values, missing entries, or skewed distributions.

Match the question to the chart

Question Useful plot Example
How does something change over time? Line plot Daily temperature
Which category is larger? Bar plot Sales by product
How are values distributed? Histogram / density plot Exam marks
Are two numeric variables related? Scatter plot Study hours vs marks
How does a pattern differ across groups? Facet grid Sales trend by region
How do numeric values vary by category? Box / violin / strip plot Salary by department

2. A brief Matplotlib API primer

Matplotlib is a widely used Python library for creating static, animated, and interactive visualizations. Its pyplot interface provides familiar functions such as plot(), bar(), and hist().

2.1 Import and basic structure

import matplotlib.pyplot as plt

x = [1, 2, 3, 4, 5]
y = [2, 4, 3, 7, 6]

plt.plot(x, y, marker="o", label="Values")
plt.title("A simple line plot")
plt.xlabel("X values")
plt.ylabel("Y values")
plt.grid(True, alpha=0.3)
plt.legend()
plt.tight_layout()
plt.show()

What each function does:

  • plt.plot(x, y): draws a line connecting the supplied points.
  • marker='o': places a circular marker at each data point.
  • plt.title(): adds a title; plt.xlabel() and plt.ylabel() label the axes.
  • plt.grid(): adds reference grid lines that help read values.
  • plt.legend(): displays labels for plotted series.
  • plt.tight_layout(): adjusts spacing to eliminate clipped labels and tight margins.
  • plt.show(): renders and displays the finished figure in a script.

2.2 Figure and Axes: object-oriented API

Matplotlib organizes a chart around a Figure (the complete outer canvas) and one or more Axes (the actual plotting areas). The object-oriented API is recommended when a figure has multiple subplots or needs precise customization. 

import matplotlib.pyplot as plt

fig, ax = plt.subplots(figsize=(7, 4))
ax.plot([1, 2, 3], [3, 5, 4], marker="o")
ax.set_title("Weekly values")
ax.set_xlabel("Week")
ax.set_ylabel("Value")
ax.grid(True, alpha=0.3)
fig.tight_layout()
plt.show()
  • fig represents the complete figure canvas.
  • ax represents one individual plotting area.
  • plt.subplots() creates the Figure and Axes together.
  • Use ax.set_title(), ax.set_xlabel(), and ax.set_ylabel() for an Axes object.

2.3 Multiple plots in one figure

fig, axes = plt.subplots(1, 2, figsize=(10, 4))

axes[0].plot([1, 2, 3], [2, 4, 3], marker="o")
axes[0].set_title("Line plot")

axes[1].bar(["A", "B", "C"], [5, 3, 7])
axes[1].set_title("Bar plot")

fig.tight_layout()
plt.show()

Here, 1, 2 means one row and two columns of plots. With multiple Axes, customize each one through axes[0], axes[1], and so on.

2.4 Common customization options

  • Color: color='teal' or hex strings like '#b41118'.
  • Line style: linestyle='--' for a dashed line, ':' for dotted.
  • Line width: linewidth=2.
  • Marker: marker='s' for squares, marker='o' for circles, '^' for triangles.
  • Transparency: alpha=0.5 (ranges from 0.0 transparent to 1.0 opaque).
  • Size: figsize=(8, 5) (width and height in inches).
  • Save figure: fig.savefig('chart.png', dpi=300, bbox_inches='tight').
Good Practice

Give every chart a meaningful title, label both axes, include units where relevant (e.g., °C, INR, kg), and use a legend only when it helps the reader distinguish multiple series.

3. Plotting with Pandas

Pandas is a Python library for working with tabular data. A DataFrame stores rows and columns; a Series stores one column or a one-dimensional sequence. Pandas plotting methods use Matplotlib behind the scenes, so Matplotlib customization can still be seamlessly applied.

3.1 Create a DataFrame

import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({
    "month": ["Jan", "Feb", "Mar", "Apr"],
    "sales": [120, 150, 135, 180],
    "cost": [80, 90, 95, 110]
})

3.2 Basic Pandas plotting

df.plot(x="month", y="sales", kind="line", marker="o",
        title="Monthly sales")
plt.ylabel("Sales (units)")
plt.tight_layout()
plt.show()

The kind argument chooses the chart type. Common values include line, bar, barh, hist, box, area, and scatter (scatter generally requires x and y columns).

3.3 Plot multiple columns

df.plot(x="month", y=["sales", "cost"], marker="o",
        title="Sales and cost by month")
plt.ylabel("Amount")
plt.tight_layout()
plt.show()

Pandas automatically uses different visual styles for the two columns and adds a legend. Always check that the columns share a meaningful scale before comparing them on one axis.

3.4 Histogram and bar chart using Pandas

# Histogram: distribution of a numeric column
marks = pd.Series([45, 50, 55, 60, 61, 65, 70, 72, 80, 92])
marks.plot(kind="hist", bins=5, edgecolor="black",
           title="Distribution of marks")
plt.xlabel("Marks")
plt.show()

# Bar chart: compare category values
df.plot(x="month", y="sales", kind="bar",
        legend=False, title="Sales by month")
plt.ylabel("Sales")
plt.tight_layout()
plt.show()

3.5 When Pandas plotting is useful

  • Quick exploratory charts directly from a DataFrame.
  • Simple charts with minimal boilerplate code.
  • Fast comparison of columns or groups immediately after data cleaning.
  • Use Seaborn or direct Matplotlib when you need more specialized statistical styling or detailed layout control.

4. Line plots

A line plot connects observations in order, usually to show a trend. It is especially useful for time series such as daily temperature, monthly sales, or yearly population.

4.1 Example

import matplotlib.pyplot as plt

months = ["Jan", "Feb", "Mar", "Apr", "May"]
temperature = [24, 26, 29, 32, 34]

plt.plot(months, temperature, marker="o",
         color="tomato", linewidth=2)
plt.title("Monthly temperature")
plt.xlabel("Month")
plt.ylabel("Temperature (°C)")
plt.grid(True, alpha=0.25)
plt.tight_layout()
plt.show()

4.2 How to read it

  • X-axis: usually time or an ordered sequence.
  • Y-axis: the measured numerical quantity.
  • Slope & Direction: Upward sections indicate increases; downward sections indicate decreases.
  • Steep sections: Indicate faster rates of change relative to chosen scales.
  • Markers: Show the actual observations; the connecting line guides the eye.

4.3 Multiple lines

days = [1, 2, 3, 4, 5]
city_a = [30, 31, 29, 32, 33]
city_b = [27, 28, 28, 29, 30]

plt.plot(days, city_a, marker="o", label="City A")
plt.plot(days, city_b, marker="s", label="City B")
plt.title("Daily temperature comparison")
plt.xlabel("Day")
plt.ylabel("Temperature (°C)")
plt.legend()
plt.show()

4.4 Advantages and limitations

  • Advantages: Clearly reveals trends, direction, turning points, and rates of change over time.
  • Limitations: Too many lines can severely clutter a chart; connecting unordered categories may falsely imply a sequence that does not exist.
  • Tip: Sort time values chronologically and handle missing dates intentionally before plotting.

5. Bar plots

A bar plot compares a numerical value across discrete categories. The length or height of each bar represents the value. Bar charts are suitable for counts, totals, averages, or other summarized measures.

5.1 Vertical and horizontal bars

categories = ["Python", "Java", "SQL"]
students = [35, 25, 30]

plt.bar(categories, students, color="steelblue")
plt.title("Students choosing each topic")
plt.xlabel("Topic")
plt.ylabel("Number of students")
plt.show()

# Horizontal bars are useful for long category names
plt.barh(categories, students)
plt.xlabel("Number of students")
plt.title("Topic preference")
plt.show()

5.2 Grouped bars

import numpy as np

labels = ["A", "B", "C"]
class_1 = [70, 82, 75]
class_2 = [74, 78, 88]

x = np.arange(len(labels))
width = 0.35

fig, ax = plt.subplots()
ax.bar(x - width/2, class_1, width, label="Class 1")
ax.bar(x + width/2, class_2, width, label="Class 2")
ax.set_xticks(x, labels)
ax.set_ylabel("Average marks")
ax.set_title("Class comparison")
ax.legend()
fig.tight_layout()
plt.show()

5.3 Bar plot versus histogram

A bar plot compares separate discrete categories; the bars can be reordered and gaps are deliberately shown between bars. A histogram groups a continuous numeric variable into adjacent intervals (bins), so the order and bin boundaries matter and bars normally touch.

5.4 Good practices

  • Start a bar chart's value axis at zero in most cases, because bar length encodes magnitude.
  • Sort bars when ranking or comparison is the primary goal.
  • Use horizontal bars (plt.barh) for long category labels to avoid overlapping text.
  • Do not use a bar chart for every numeric distribution; use a histogram when the question is about continuous distributions.

6. Histograms and density plots

6.1 Histogram

A histogram divides numeric values into intervals called bins and counts how many observations fall in each bin. It helps reveal shape, spread, skewness, clusters, and possible outliers. 

marks = [45, 50, 52, 55, 58, 60, 61, 65, 70, 72, 80, 92]

plt.hist(marks, bins=5, edgecolor="black")
plt.title("Distribution of exam marks")
plt.xlabel("Marks")
plt.ylabel("Frequency")
plt.show()

Bin choice matters: too few bins can hide underlying structure; too many bins can make random noise look like meaningful peaks. Try a few reasonable settings and explain your choice.

6.2 Frequency, probability and density

  • Frequency: the raw count of observations falling in each bin.
  • Probability-style histogram: bars are scaled so their heights represent proportions under the chosen binning.
  • Density histogram: the total area of all bars integrates to 1; density height is not the same as raw count.
plt.hist(marks, bins=5, density=True, alpha=0.6,
         edgecolor="black")
plt.title("Density-scaled histogram")
plt.ylabel("Density")
plt.show()

6.3 Density plot / KDE

A kernel density estimate (KDE) is a smooth estimate of a variable's continuous distribution. It can make the overall shape easier to see, but it is an estimate—not a set of exact counts. Its appearance depends heavily on the bandwidth (smoothing level). 

import seaborn as sns

sns.kdeplot(data=marks, fill=True)
plt.title("KDE of exam marks")
plt.xlabel("Marks")
plt.show()

6.4 Histogram with density curve

sns.histplot(data=marks, bins=5, stat="density",
             kde=True, edgecolor="white")
plt.title("Marks: histogram and KDE")
plt.xlabel("Marks")
plt.show()

6.5 Shape vocabulary

  • Symmetric: left and right sides look roughly alike around the center.
  • Right-skewed: a long tail extends toward larger positive values (mean > median).
  • Left-skewed: a long tail extends toward smaller negative values (mean < median).
  • Bimodal: two prominent peaks; this may indicate two underlying subgroups or subpopulations.
  • Outlier: an observation far from most of the data; investigate it rather than automatically deleting it.
Important Note on KDE

KDE curves can extend beyond the observed data range (e.g. negative exam marks) and can smooth away small groups. Use a histogram as a complementary view, especially for small datasets.

7. Scatter plots

A scatter plot displays paired numeric values as points. Each point represents one observation, with one variable on the x-axis and another on the y-axis. It is used to inspect association, clusters, outliers, and nonlinear patterns.

7.1 Basic scatter plot

hours = [1, 2, 2.5, 3, 4, 5, 6]
marks = [42, 48, 55, 58, 68, 75, 85]

plt.scatter(hours, marks, alpha=0.8)
plt.title("Study hours and exam marks")
plt.xlabel("Study hours")
plt.ylabel("Exam marks")
plt.show()

7.2 Interpret the pattern

  • Positive association: larger x values tend to occur with larger y values (upward trend).
  • Negative association: larger x values tend to occur with smaller y values (downward trend).
  • Little visible association: points form a random cloud; no clear trend.
  • Nonlinear association: the relationship follows a curved or U-shaped pattern rather than a straight line.
  • Clusters: points form distinct groups that may represent different populations or conditions.
  • Outliers: points far from the main cloud deserve careful investigation.

7.3 Add a third variable

size = [30, 50, 70, 40, 90, 60, 80]
group = ["A", "A", "B", "B", "A", "B", "A"]
colors_by_group = ["tab:blue" if g == "A" else "tab:orange"
                   for g in group]

plt.scatter(hours, marks, s=size, c=colors_by_group, alpha=0.7)
plt.xlabel("Study hours")
plt.ylabel("Exam marks")
plt.title("Scatter plot with group color and point size")
plt.show()

Color can encode a category, and point size can encode another numeric measure. Add a legend or clear explanation when using visual encodings; otherwise readers may not know what the colors or sizes mean.

7.4 Correlation is not causation

A visible relationship does not prove that one variable causes the other. A third confounding factor may influence both, or the pattern may arise purely by chance. Scatter plots are exploratory tools, not causal proof.

7.5 Overplotting

When many points overlap, the plot can hide how many observations are present. Reduce marker size, use transparency (alpha), or consider a hexbin / 2D density plot for very large datasets.

8. Seaborn: statistical visualization

Seaborn is a statistical visualization library built on Matplotlib. It works naturally with Pandas DataFrames, offers attractive default styles, and makes it easy to map columns to visual properties such as color, marker style, or row/column panels.

8.1 Setup and long-form data

import seaborn as sns
import pandas as pd
import matplotlib.pyplot as plt

df = pd.DataFrame({
    "month": ["Jan", "Feb", "Mar", "Jan", "Feb", "Mar"],
    "sales": [10, 14, 13, 8, 11, 12],
    "region": ["North", "North", "North", "South", "South", "South"]
})

In long-form data, each row is one observation and columns identify variables. This layout often works well with Seaborn because the chart can map columns directly to x, y, hue, and other visual roles.

8.2 Seaborn syntax

sns.lineplot(data=df, x="month", y="sales", hue="region",
             marker="o")
plt.title("Sales by month and region")
plt.show()

data supplies the DataFrame; x and y name columns; hue splits or colors the data by a category. Seaborn automatically aggregates repeated observations and may display uncertainty intervals depending on settings.

8.3 Common Seaborn functions

Function Purpose
sns.lineplot() Trend or relationship along an ordered x-axis
sns.barplot() Estimate a numeric statistic for each category (often mean)
sns.countplot() Count observations in each category
sns.histplot() Histogram, optionally with KDE
sns.kdeplot() Smoothed density estimate
sns.scatterplot() Relationship between two numeric variables
sns.boxplot() Compare distributions and potential outliers by category
sns.violinplot() Show distribution shape by category
sns.stripplot() Show individual observations by category
sns.pairplot() Explore pairwise relationships among several variables
sns.heatmap() Display values in a matrix, often a correlation matrix

9. Facet grids

A facet grid splits a dataset into multiple small charts, one for each category or combination of categories. This makes it easier to compare groups while keeping the same chart design.

9.1 FacetGrid example

tips = sns.load_dataset("tips")

g = sns.FacetGrid(tips, col="time", row="sex",
                  height=3, aspect=1.1)
g.map_dataframe(sns.scatterplot, x="total_bill",
                y="tip", alpha=0.7)
g.set_axis_labels("Total bill", "Tip")
g.set_titles(row_template="{row_name}",
             col_template="{col_name}")
plt.show()

The built-in Seaborn tips dataset is used in this example. If downloading built-in datasets is unavailable in your environment, replace it with your own DataFrame containing the columns used in the code.

9.2 relplot: a convenient figure-level function

sns.relplot(data=tips, x="total_bill", y="tip",
            hue="smoker", col="time", kind="scatter",
            height=3)
plt.show()

relplot() can create relational plots and split them across facets. col creates columns of panels, while row creates rows. hue distinguishes groups by color.

9.3 Benefits and cautions

  • Benefits: Side-by-side comparisons, visible group differences, less overplotting than cramming every group into a single plot.
  • Keep axes comparable: Ensure axis limits are aligned when the goal is comparing magnitudes across facets.
  • Avoid too many categories: Too many levels generate tiny, unreadable subplots.
  • Check sample sizes: A pattern in a group with very few observations may be statistically unstable.

10. Categorical data visualization

Categorical variables contain labels or groups, such as department, product type, region, or pass/fail status. Categorical plots compare categories or show the distribution of numeric values within each category.

10.1 Count plot

students = pd.DataFrame({
    "course": ["Python", "Java", "Python", "SQL",
               "Java", "Python", "SQL", "Python"]
})

sns.countplot(data=students, x="course")
plt.title("Number of students by course")
plt.show()

A count plot counts rows in each category. It is useful when the raw data contains one row per observation and you want category frequencies.

10.2 Bar plot for a summary statistic

scores = pd.DataFrame({
    "class": ["A", "A", "A", "B", "B", "B"],
    "marks": [70, 75, 80, 65, 78, 82]
})

sns.barplot(data=scores, x="class", y="marks", errorbar=None)
plt.title("Average marks by class")
plt.ylabel("Mean marks")
plt.show()

Unlike countplot(), barplot() summarizes a numeric variable for each category. By default, it commonly estimates a mean and can show uncertainty intervals.

10.3 Box plot

sns.boxplot(data=scores, x="class", y="marks")
plt.title("Marks distribution by class")
plt.show()
  • The line inside the box is the median.
  • The box spans the first to third quartiles (the interquartile range, IQR).
  • Whiskers extend according to the plotting convention; in Seaborn's usual box plot, they typically reach the most extreme points within 1.5 × IQR of the quartiles.
  • Points beyond the whiskers are flagged as potential outliers, not automatically errors.

10.4 Violin and strip plots

sns.violinplot(data=scores, x="class", y="marks", inner="quartile")
plt.title("Distribution shape by class")
plt.show()

sns.stripplot(data=scores, x="class", y="marks", jitter=True)
plt.title("Individual marks by class")
plt.show()

A violin plot shows a smoothed distribution shape for each category. A strip plot displays individual observations. With small datasets, a strip plot can be more transparent; with larger datasets, combine or overlay plots thoughtfully.

10.5 Choosing the right categorical plot

  • Category frequency: countplot()
  • Compare a numeric summary across categories: barplot()
  • Compare median, spread, and potential outliers: boxplot()
  • Compare distribution shapes: violinplot()
  • Show every individual observation: stripplot() or swarmplot()

11. Other Python visualization tools

Matplotlib, Pandas, and Seaborn are not the only options. The best tool depends on whether you need interactive exploration, browser-based dashboards, maps, or a specialized statistical display.

11.1 Plotly

Plotly creates interactive charts with hover details, zooming, and legends that users can toggle. It is useful for interactive reports and web applications. 

# Install: python -m pip install plotly
import plotly.express as px
import pandas as pd

df = pd.DataFrame({
    "month": ["Jan", "Feb", "Mar"],
    "sales": [120, 150, 135]
})

fig = px.line(df, x="month", y="sales",
              markers=True, title="Monthly sales")
fig.show()

11.2 Bokeh

Bokeh supports interactive browser-based visualizations and linked charts. It can be useful when an application needs interactive tools and a Python-centered workflow. 

# Install: python -m pip install bokeh
from bokeh.plotting import figure, show

p = figure(title="Simple Bokeh line", x_axis_label="x",
           y_axis_label="y")
p.line([1, 2, 3], [2, 5, 3], line_width=2)
show(p)

11.3 Altair

Altair is a declarative visualization library. You describe how data fields map to x, y, color, and marks rather than specifying every drawing step. It is concise for many statistical charts. 

# Install: python -m pip install altair
import altair as alt
import pandas as pd

df = pd.DataFrame({
    "month": ["Jan", "Feb", "Mar"],
    "sales": [120, 150, 135]
})

chart = alt.Chart(df).mark_line(point=True).encode(
    x="month:N", y="sales:Q"
).properties(title="Monthly sales")
chart

11.4 Other tools to know

  • HoloViews: high-level plotting built around data and visualization objects; can work with multiple plotting backends.
  • Datashader: helps render very large datasets by aggregating data into pixels, reducing overplotting.
  • GeoPandas / Folium: useful for geospatial data and interactive maps.
  • Dash / Streamlit: application frameworks for building dashboards around charts and controls.
  • Pygal: Python charting library focused on SVG output; check project maintenance and compatibility before choosing it for a new project.

12. A complete mini example

This example puts several topics together: a DataFrame, a line plot, a histogram, a scatter plot, and a categorical comparison. Run each section separately if you want to study one chart at a time. 

import pandas as pd
import matplotlib.pyplot as plt
import seaborn as sns

df = pd.DataFrame({
    "student": ["A", "B", "C", "D", "E", "F"],
    "hours": [1, 2, 2.5, 3, 4, 5],
    "marks": [42, 48, 55, 58, 68, 75],
    "group": ["X", "X", "Y", "Y", "X", "Y"]
})

# 1. Scatter plot: study hours versus marks
sns.scatterplot(data=df, x="hours", y="marks", hue="group")
plt.title("Study hours and marks")
plt.tight_layout()
plt.show()

# 2. Histogram: distribution of marks
sns.histplot(data=df, x="marks", bins=5, kde=True)
plt.title("Distribution of marks")
plt.tight_layout()
plt.show()

# 3. Categorical summary: marks by group
sns.boxplot(data=df, x="group", y="marks")
plt.title("Marks by group")
plt.tight_layout()
plt.show()

Notice that the same dataset can support different questions. The scatter plot asks about the relationship between two numeric variables; the histogram asks how marks are distributed; the box plot compares marks across groups.

13. Common mistakes and debugging

  • Missing import: Use import matplotlib.pyplot as plt and import Pandas/Seaborn when needed.
  • Wrong column name: Check spelling and capitalization with print(df.columns).
  • Chart not visible in a script: Remember to add plt.show().
  • Labels cut off: Use plt.tight_layout() or fig.tight_layout().
  • Unexpected order: Explicitly sort dates or define category order before plotting.
  • Wrong plot type: Use bars for categories and histograms for numeric distributions.
  • Too many overlapping points: Reduce marker size, add transparency (alpha), or aggregate the data.
  • Misleading scale: Check axis limits and units; avoid visually exaggerating differences by omitting baseline zeros on bar charts.
  • Seaborn version mismatch: Some parameters differ between versions (e.g., errorbar=None vs older ci=None); inspect the error message and installed version before changing the entire program.

15. Practice questions

Q1. What is data visualization? Give three benefits.
Answer: Visual representation of data using charts, plots, and graphs. Benefits include: revealing hidden patterns, comparing groups or trends, and communicating complex insights clearly to non-technical stakeholders.
Q2. Explain the difference between a Figure and an Axes in Matplotlib.
Answer: A Figure is the entire top-level canvas window. An Axes is the actual sub-region on that canvas where data points, labels, and ticks are plotted. One Figure can contain one or multiple Axes.
Q3. Write Python code to create a line plot with a title and labeled axes.
Answer: plt.plot(x, y); plt.title("My Plot"); plt.xlabel("X"); plt.ylabel("Y"); plt.show()
Q4. When would you choose a bar plot instead of a histogram?
Answer: Choose a bar plot when comparing discrete categorical groups (e.g., product types, departments). Choose a histogram when inspecting the distribution of a single continuous numerical variable.
Q5. What are bins in a histogram? How can the number of bins change the appearance?
Answer: Bins are equal intervals that divide the continuous range. Too few bins over-smooth the data and conceal key structures; too many bins introduce excessive noise and jagged peaks.
Q6. What is the difference between frequency and density in a histogram?
Answer: Frequency represents raw observation counts per bin. Density scales bar heights so that the total area under all bars equals 1, allowing comparison between datasets of different sample sizes.
Q7. What does a KDE plot show, and why is its shape an estimate?
Answer: A KDE shows a smoothed probability density curve of the data. It is an estimate because it applies kernel smoothing with a selected bandwidth rather than displaying exact discrete counts.
Q8. How can you interpret positive, negative, and nonlinear patterns in a scatter plot?
Answer: Positive: points slope upward as x increases; Negative: points slope downward as x increases; Nonlinear: points form a distinct curved trajectory rather than a straight line.
Q9. What does the Seaborn parameter hue do?
Answer: hue maps a categorical or numeric variable to color, splitting plotted markers or lines into distinct visual groups with an automatic legend.
Q10. Explain FacetGrid and give one situation where it is useful.
Answer: FacetGrid splits a dataset into small multiple subplots across rows and columns of categories. It is useful for comparing relationships (e.g., bill vs tip) across subsets (e.g., lunch vs dinner, smoker vs non-smoker) without overcrowding.
Q11. Differentiate countplot() and barplot().
Answer: countplot() counts raw row frequencies for each category. barplot() aggregates and calculates a statistical summary (such as the mean) of a second numeric column for each category.
Q12. Compare Matplotlib, Pandas plotting, Seaborn, and Plotly.
Answer: Matplotlib provides low-level publication control; Pandas plotting offers quick exploratory charts directly from DataFrames; Seaborn automates statistical aesthetics and grouping; Plotly creates interactive, web-ready charts with zooming and hover tooltips.
Q13. Name two ways to reduce overplotting in a scatter plot.
Answer: 1) Decrease marker size and add transparency using alpha; 2) Use a 2D density plot or hexbin plot.
Q14. Why does correlation not necessarily imply causation?
Answer: Two variables can correlate due to a third confounding variable, reverse causation, or pure coincidence. True causation requires controlled experimentation or rigorous causal inference frameworks.
Q15. List four common chart design practices that improve readability.
Answer: 1) Provide clear, descriptive titles; 2) Label both axes with variable names and measurement units; 3) Start bar chart axes at zero; 4) Use legends and colors purposefully without visual clutter.
