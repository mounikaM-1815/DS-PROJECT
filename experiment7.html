1. Introduction to Data Aggregation

Data Aggregation is the process of grouping raw observational records into meaningful summary metrics. In Pandas, aggregation follows the classic Split-Apply-Combine paradigm introduced by Hadley Wickham:

The Split-Apply-Combine Strategy

1. Split: The DataFrame is broken down into subsets based on distinct values in one or more grouping keys (e.g., Department, Year, or species).
2. Apply: A statistical aggregation function (such as mean(), sum(), std(), min(), max(), or count()) is computed independently on each group.
3. Combine: The aggregated results from all groups are assembled into a new structured DataFrame or Series.

Part A

GroupBy Method using Single Key and Multiple Keys

Create a tabular dataset representing student examination records across academic departments and academic years. Group the dataset first by a single key (Department) and then by multiple keys (['Department', 'Year']).

Python Implementation: Single & Multiple Keys GroupBy 
import pandas as pd

# Create a tabular dataset
data = {
   'Name': ['Ravi', 'Sita', 'Arun', 'Priya', 'Kiran', 'Anil', 'Lakshmi', 'Rahul'],
   'Department': ['CSE', 'CSE', 'ECE', 'ECE', 'CSE', 'ECE', 'CSE', 'ECE'],
   'Year': [2, 2, 3, 3, 2, 3, 3, 2],
   'Marks': [85, 90, 78, 88, 75, 82, 95, 70]
}

# Create DataFrame
df = pd.DataFrame(data)

print("Original DataFrame:")
print(df)

# 1. Group by a SINGLE KEY
print("\n1. Group by Department:")

group1 = df.groupby('Department')

for name, group in group1:
   print("\nDepartment:", name)
   print(group)

# Calculate average marks for each department
print("\nAverage Marks by Department:")
print(df.groupby('Department')['Marks'].mean())

# 2. Group by MULTIPLE KEYS
print("\n2. Group by Department and Year:")

group2 = df.groupby(['Department', 'Year'])

for name, group in group2:
   print("\nGroup:", name)
   print(group)

# Calculate average marks for each Department and Year
print("\nAverage Marks by Department and Year:")
print(df.groupby(['Department', 'Year'])['Marks'].mean())
Explanation:
  • df.groupby('Department'): Splits the dataset into groups based on unique department labels (CSE and ECE).
  • for name, group in group1:: Iterates through each group where name is the group key and group is a subset DataFrame.
  • df.groupby(['Department', 'Year']): Creates hierarchical grouping based on combinations of department and student year (e.g., ('CSE', 2), ('CSE', 3)).
  • ['Marks'].mean(): Selects the Marks column from each group and applies the arithmetic mean.

Part B

Compute Summary Statistics using aggregate() Method

Compute multiple statistical aggregations (sum, mean, and std) across multiple numeric features (Marks and Attendance) grouped by academic department using the dictionary mapping syntax of aggregate().

Python Implementation: Multi-Metric aggregate() 
import pandas as pd

# Create a DataFrame
data = {
   'Department': ['CSE', 'CSE', 'CSE', 'ECE', 'ECE', 'ECE',
                  'EEE', 'EEE', 'EEE'],
   'Marks': [80, 75, 85, 70, 65, 75, 90, 85, 95],
   'Attendance': [90, 85, 95, 80, 75, 85, 95, 90, 100]
}

df = pd.DataFrame(data)

print("Original DataFrame:")
print(df)

# Group data by Department and calculate summary statistics
result = df.groupby('Department').aggregate({
   'Marks': ['sum', 'mean', 'std'],
   'Attendance': ['sum', 'mean', 'std']
})

print("\nSummary Statistics:")
print(result)
Explanation:
  • aggregate({ 'Marks': ['sum', 'mean', 'std'], 'Attendance': ['sum', 'mean', 'std'] }): Applies a customized set of aggregation functions to each specific column.
  • Produces a MultiIndex column hierarchy with level 0 as feature names and level 1 as statistical metrics.
  • Standard deviation (std) evaluates variability around the mean for each departmental group.

Quick Aggregation Reference & Syntax Summary

Concise syntax patterns for performing single-metric and multi-metric aggregations:

Core Aggregation Syntax 
import pandas as pd

# 7. Data Aggregation
# a. GroupBy and Aggregation
df = pd.DataFrame({
    'Category': ['A', 'A', 'B', 'B'],
    'Data': [10, 20, 30, 40]
})
grouped = df.groupby('Category')

print("a. GroupBy and Aggregation (Sum):")
print(grouped['Data'].sum())

# b. Multiple Aggregates
print("\nb. Multiple Aggregates (Mean and Std):")
print(grouped['Data'].agg(['mean', 'std']))

Method / Function Description
df.groupby(col) Groups DataFrame rows based on unique values in col
df.groupby([col1, col2]) Groups rows by multi-column combinations creating hierarchical index
group['col'].sum() Calculates sum of elements in each group
group['col'].mean() Calculates arithmetic mean for each group
group['col'].std() Calculates sample standard deviation for each group
group.agg(['fn1', 'fn2']) Computes multiple aggregation functions in parallel
df['col'].value_counts() Counts occurrences of unique categories in a series
